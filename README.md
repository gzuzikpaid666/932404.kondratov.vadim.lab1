Языковой энтузиаст и переводчик

Лабораторная работа №1, Вариант №17, представляющая собой персональную веб-страницу. Страница разработана с использованием HTML и инлайн-стилей.

Содержание страницы
Шапка (<header>): Вадим Кондратов и профессия.

Навыки: Список ключевых компетенций

Проекты: Нумерованный список выполненных работ

Изображение: Флаг Казахстана

Форма обратной связи: Поля для ввода имени, email и сообщения с кнопкой отправки

Боковая панель (<aside>): Информация о языке, который я мечтаю выучить 

Подвал (<footer>): Копирайт и год создания.

Дизайн
Цветовая гамма: Бирюзово-белая

Стилизация: Все CSS-стили прописаны непосредственно в атрибутах style HTML-тегов (инлайн-стили) в соответствии с требованиями задания

Технологии

HTML5 (семантические теги: header, main, section, aside, footer)

Базовые элементы форм (input, textarea, button)
